# 03: Brutalist Silicon Canvas Renderer & Touch Controls

**What to build:**
A visual rendering layer implementing the validated Variant B aesthetic (parchment white `#f5f4ef`, dense black ink borders, International Klein Blue `#0022ff` prompt node, bold satirical obstacle typography, and trail particles). Bridges browser touch/pointer events to the game engine with full mobile viewport locking.

- [x] Prevents iOS/Android pull-to-refresh and unwanted page scrolling gestures
